المستكشفون المنسيون | Forgotten Explorers  (النسخة المتقدمة)
=========================================================
التشغيل: افتح index.html في المتصفح (لا يحتاج سيرفر ولا تثبيت). الإنترنت مطلوب فقط لخط Cairo (له بديل تلقائي).

الملفات
- index.html : الصفحة
- style.css  : التصميم
- data.js    : القصص والأسئلة والمصادر والخط الزمني والمقارنات
- app.js     : المنطق
- audio/     : التسجيلات الصوتية (mp3)
- scenes.js  : رسوم الكروكي المتحركة (مشهد لكل فقرة، تتحرك الشخصية أثناء الكلام)

ربط التسجيلات الصوتية (في data.js، حقل audio لكل شخصية)
- audio/spirit.mp3      → سبيريت
- audio/opportunity.mp3 → أوبورتيونيتي
- audio/ingenuity.mp3   → إنجينيويتي
- audio/alsep.mp3       → محطة ألسيب
إن كان تسجيل في غير مكانه، بدّل اسمي الملفين فقط. وإن لم يوجد الملف تعمل القراءة الآلية تلقائيًا.

المزايا
- مشهد كروكي أطفال متحرك لكل مستكشف يتغير مع كل فقرة من القصة (يمكن الضغط على النقاط للتنقل بين المشاهد)
- مشغل صوتي كامل: تشغيل/إيقاف، شريط تقدم، ±10 ثوان، سرعة 0.75–1.5×، النقر على أي فقرة للقفز إليها، تظليل الفقرة الحالية
- سؤالان تحدٍّ لكل مستكشف مع نجوم، واحتفال، وحفظ التقدم تلقائيًا
- حلقة تقدم، أرقام متحركة، مقارنة «المخطط مقابل الفعلي»، خط زمني تفاعلي
- شهادة قابلة للتحميل باسم الطالب، ومشاركة الروابط (#spirit مثلًا)
- إمكانية الوصول: تنقل بلوحة المفاتيح، مسافة = تشغيل، Esc = إغلاق، تكبير/تصغير الخط، تقليل الحركة
- متجاوب مع الجوال، ويعمل دون سيرفر
راجع الأرقام والروابط وقواعد التحدي قبل التسليم.
